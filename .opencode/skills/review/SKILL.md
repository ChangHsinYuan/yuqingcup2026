# Review Skill — 审片标准与打分规范

## 4 维度打分（每维 1-10）

### 1. Consistency（一致性）
画面内容与 scene_desc 的匹配度。

| 分数 | 标准 |
|------|------|
| 9-10 | 完美匹配描述中所有要素（主体、动作、环境、光线） |
| 7-8 | 主体和环境匹配，细节有小偏差 |
| 5-6 | 主体匹配但环境或动作有明显偏差 |
| 3-4 | 主体或环境与描述严重不符 |
| 1-2 | 完全不匹配 |

### 2. Quality（画质）
画面清晰度、色彩、构图。

| 分数 | 标准 |
|------|------|
| 9-10 | 清晰、色彩丰富、构图优美 |
| 7-8 | 清晰、色彩自然、构图合理 |
| 5-6 | 轻微模糊或色彩平淡 |
| 3-4 | 明显模糊、过曝/欠曝、构图差 |
| 1-2 | 严重画质问题 |

### 3. Motion（运动）
运动自然度、流畅度。

| 分数 | 标准 |
|------|------|
| 9-10 | 运动自然流畅，符合物理规律 |
| 7-8 | 运动基本自然，轻微不流畅 |
| 5-6 | 运动有些僵硬或不自然 |
| 3-4 | 运动明显不自然或卡顿 |
| 1-2 | 几乎无运动或运动严重异常 |

### 4. Artifact（伪影）
无明显 AI 生成痕迹。

| 分数 | 标准 |
|------|------|
| 9-10 | 无任何伪影 |
| 7-8 | 极轻微伪影，不引人注意 |
| 5-6 | 有一些可见伪影（边缘模糊、轻微融合） |
| 3-4 | 明显伪影（畸形肢体、融合、闪烁） |
| 1-2 | 严重伪影，无法使用 |

## 通过标准

- 综合分 = 四维均值
- **≥7 分通过**
- `<7 分不通过，需要重做`

## 输出格式

严格 JSON，不加任何解释文字：

```json
{
  "score": 8,
  "dimensions": {
    "consistency": 8,
    "quality": 9,
    "motion": 7,
    "artifact": 8
  },
  "feedback": "画面与描述一致，月球场景还原好；猫的运动稍显僵硬，第二帧姿态不自然。建议优化运动描述。",
  "pass": true
}
```

## feedback 写作要求

- 先说优点，再指出问题
- 问题要具体（指出哪一帧、什么问题）
- 如果不通过，给出改进建议（可指导 prompt 优化方向）
- 中文，1-3 句话
